# 📝 メモ帳アプリ

シンプルで使いやすいメモアプリです。データはブラウザに保存されるので、ページを更新しても消えません。

## 機能

- メモの作成・編集・削除
- タイトルと本文を入力できる
- カテゴリ分け（家のこと・仕事・副業・子ども・その他）
- 重要メモをピン留め（一覧の上に固定表示）
- 完了チェック機能
- タイトル・本文で検索
- 作成日時・更新日時を表示
- データは localStorage に自動保存
- スマホ対応（レスポンシブデザイン）

## 起動方法

### 1. 必要なパッケージをインストール

```bash
cd memo-app
npm install
```

### 2. 開発サーバーを起動

```bash
npm run dev
```

### 3. ブラウザで開く

ターミナルに表示された URL（例: `http://localhost:5173`）をブラウザで開いてください。

## ファイル構成

```
memo-app/
├── src/
│   ├── App.jsx               # メイン画面・状態管理
│   ├── App.css               # スタイル（デザイン）
│   ├── main.jsx              # アプリの起動ファイル
│   ├── index.css             # グローバルCSS
│   └── components/
│       ├── MemoList.jsx      # 左サイドバーのメモ一覧
│       ├── MemoEditor.jsx    # 右パネルの編集フォーム
│       └── SearchBar.jsx     # 検索バー
├── index.html
├── package.json
└── README.md
```

## 使い方

| 操作 | 方法 |
|------|------|
| 新規作成 | 左上の「＋ 新規」ボタン |
| 編集 | 一覧からメモをクリック → 右パネルで編集（自動保存） |
| 削除 | メモにカーソルを当てて 🗑️ ボタン、または編集画面の「削除」 |
| ピン留め | 📌 ボタンで一覧の上に固定 |
| 完了 | ✅ ボタンで完了マークをつける |
| 検索 | 上部の検索欄に入力（タイトル・本文を検索） |
| カテゴリ絞り込み | カテゴリタブをクリック |
